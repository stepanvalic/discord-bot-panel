Virtual Environment Information

This panel uses two separate virtual environments:

  • Panel Virtual Environment: Used by the panel itself. Located in the root directory.
  • Bot Virtual Environment: Used by the hosted Discord bot. Located inside the bot's directory.

When you install requirements, they will be installed in the bot's virtual environment. The bot will run using bash commands through this environment.
