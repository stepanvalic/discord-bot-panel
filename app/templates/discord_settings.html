How It Works

The Discord avatar system works as follows:

  1. Users provide their Discord ID in their profile settings
  2. The system periodically fetches avatars from Discord API using the bot token
  3. Avatars are stored in the database and displayed in the UI
  4. The bot runs in offline mode and only connects to Discord API when fetching avatars

Note: The bot token is stored securely in the database and is only used for fetching avatars. The bot does not need to be added to any Discord server.
