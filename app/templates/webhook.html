            Webhooks allow your bot to receive notifications when changes are pushed to your Git repository.

  1. Go to your repository settings
    2.

    3. 
            
  3. Add a new webhook with the URL shown above
    4. 
            
  4. Set the secret/token to the key shown above
    5.

What is this for?

        

            Discord webhooks allow you to send status updates to your Discord server.
            The combined status webhook will be updated every minute with the current status of both the panel and the bot in a single message.
            This provides a comprehensive overview of your entire system in one place.
        

        

            To set up a webhook in Discord:
        

        
    
            
  1. Go to your Discord server settings
    2. 
            
  2. Select "Integrations" and then "Webhooks"
    3. 
            
  3. Click "New Webhook"
    4. 
            
  4. Give it a name (e.g., "Bot Panel Status")
    5. 
            
  5. Select the channel where you want the messages to appear
    6. 
            
  6. Click "Copy Webhook URL" and paste it in the form above
    7.
